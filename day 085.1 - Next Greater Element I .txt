# 🔍 Next Greater Element I — Java Solution

## 📌 Problem
You are given two integer arrays **nums1** and **nums2**, where nums1 is a subset of nums2.  
For each element in nums1, find the **next greater element** in nums2.  
The next greater element is the **first element to the right** of it in nums2 that is strictly larger.

If it doesn’t exist, return **-1** for that element.

---

## ✅ Example
**Input:**  
nums1 = [4,1,2]  
nums2 = [1,3,4,2]

**Output:**  
[-1,3,-1]

Explanation:  
- For 4 → no greater element to its right → -1  
- For 1 → next greater is 3  
- For 2 → no greater element → -1  

---

## 🧠 Approach
- First store the **index of every element** of nums2 in a HashMap for O(1) lookup.  
- For each element in nums1:
  1. Jump to its index in nums2.
  2. Scan rightward until a greater element is found.
  3. If found → store it.  
  4. Else → store -1.

This is a **direct simulation** approach.

---

## ⏱️ Time & Space Complexity
- **Time Complexity:** O(n * m) in worst case (nested scan)  
- **Space Complexity:** O(m) for the HashMap  

---

## 🧩 Java Code (Your Implementation)
```java
class Solution {
    public int[] nextGreaterElement(int[] nums1, int[] nums2) {
        int n = nums1.length;
        HashMap<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums2.length; i++) {
            map.put(nums2[i], i);
        }

        int ans[] = new int[n];

        for (int i = 0; i < n; i++) {
            int x = nums1[i];
            int j = map.get(x);
            ans[i] = -1;

            for (j = j; j < nums2.length; j++) {
                if (nums2[j] > x) {
                    ans[i] = nums2[j];
                    break;
                }
            }
        }
        return ans;
    }
}
