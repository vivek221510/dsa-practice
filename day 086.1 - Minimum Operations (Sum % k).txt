# 🧮 Problem: Minimum Operations (Sum % k)

Given an integer array `nums` and an integer `k`, compute the minimum operations needed based on the rule:

Return:
    sum(nums) % k

This uses the total sum of the array and takes its remainder when divided by `k`.

---

## ✅ Example

Input:
nums = [1, 2, 3]
k = 4

Sum = 6
6 % 4 = 2

Output:
2

---

## 💡 Approach
1. Loop through the array.
2. Compute the sum.
3. Return `sum % k`.

---

## ⏱️ Time & Space Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)

---

## 🧾 Java Code

class Solution {
    public int minOperations(int[] nums, int k) {
        
        int sum = 0;
        for(var x : nums)
        {
            sum += x;
        }
        return sum % k;
    }
}
